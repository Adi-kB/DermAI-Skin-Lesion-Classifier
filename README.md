🩺 DermAI: Deep Learning Skin Lesion Classifier

DermAI is a specialized medical imaging tool that uses a **Convolutional Neural Network (CNN)** to classify skin lesions into 7 distinct categories with high precision.

## 🚀 Key Features
* **High Accuracy:** Achieves ~97% confidence on validated test cases.
* **Large-Scale Data:** Trained on the **HAM10000** dataset (10,000+ dermatoscopic images).
* **Responsive UI:** Built with Streamlit for real-time analysis and user feedback.
* **Safety First:** Includes automated medical disclaimers and confidence scoring.

## 🛠 Tech Stack
* **Language:** Python 3.9+
* **Deep Learning:** TensorFlow / Keras (CNN Architecture)
* **DevOps:** Git LFS (Large File Storage) for model management
* **Frontend:** Streamlit & Custom CSS

## 📋 How to Run
1. Clone the repo: `git clone https://github.com/Adi-kB/DermAI-Skin-Lesion-Classifier.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
